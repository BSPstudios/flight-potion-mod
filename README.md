# BSP's Potion Mod — Fly Away!

A Minecraft mod that adds new potions and brewing recipes, including a **Flight Potion**
(free creative-style flight) and an **Antidote Potion** (immunity to poison).

> 一个 Minecraft 药水模组：加入**飞行药水**（像创造模式一样自由飞行）和**防中毒药水**（效果期间免疫中毒）。

## ⬇️ Download / 下载

**All downloads are on the [Releases](../../releases) page.**
请到 **[Releases](../../releases)** 页面下载。

Each release contains the `.jar` for that version. Pick the file matching your
Minecraft version and loader (Fabric / Forge).

每个 Release 内含对应版本的 `.jar`，请选择与你 Minecraft 版本、加载器（Fabric / Forge）匹配的文件。

## Features / 功能

- **Flight Potion** — creative-style flight while active. / 飞行药水：效果期间像创造模式一样自由飞行。
- **Antidote Potion** — clears and blocks poison while active. / 防中毒药水：效果期间免疫并清除中毒。
- **Brewing recipes** / 酿造配方：
  - Awkward Potion + Feather → Flight Potion（粗制的药水 + 羽毛 → 飞行药水）
  - Flight Potion + Redstone → Extended Flight Potion（飞行药水 + 红石 → 长效飞行药水）
  - Awkward Potion + Milk Bucket → Antidote Potion（粗制的药水 + 奶桶 → 防中毒药水）
  - Antidote Potion + Redstone → Extended Antidote Potion（防中毒药水 + 红石 → 长效防中毒）
  - Antidote Potion + Fermented Spider Eye → Potion of Poison（防中毒药水 + 发酵蛛眼 → 中毒药水）
- Custom mob-effect icons / 自定义效果图标
- Bonus music disc / 彩蛋唱片

## Installation / 安装

1. Install [Fabric Loader](https://fabricmc.net/use/) or [Forge](https://files.minecraftforge.net/)
   for your Minecraft version. / 安装对应版本的 Fabric 或 Forge。
2. Put the matching `.jar` into your `mods/` folder. / 把匹配的 `.jar` 放进 `mods` 文件夹。
3. Launch. **Client and server both need the mod.** / 启动。**客户端和服务端都需要安装此模组。**

## Compatibility / 兼容性

- Minecraft: Java Edition
- Loaders: Fabric, Forge
- Environment: **Client and server, required on both**
